# Sharp Sites Web

Sharp Sites Web is my freelance web development business focused on helping businesses build modern, professional, and responsive websites.

The site serves as both the online home for Sharp Sites Web and a showcase of the kind of design and development work I provide for clients.

## Live Site

**https://www.sharpsitesweb.com/**

## About Sharp Sites Web

Sharp Sites Web was created to help businesses establish or improve their online presence through websites that are clean, responsive, easy to use, and tailored to their individual needs.

I handle the development process from the initial idea through launch, including:

* Project planning
* Website design
* Frontend development
* Responsive/mobile design
* Deployment
* Domain configuration
* Client revisions
* Ongoing maintenance and improvements

The goal is not simply to put a business online, but to create a website that feels professional, represents the business well, and makes it easier for customers to interact with the brand.

## Development Approach

My approach to Sharp Sites Web combines development, design, problem solving, and direct client communication.

Each project starts by understanding what the client actually needs rather than forcing every business into the same template.

From there, I focus on:

1. Understanding the business and its goals
2. Planning the structure and user experience
3. Creating a responsive visual design
4. Building the website
5. Testing across screen sizes
6. Incorporating client feedback
7. Deploying the finished product
8. Supporting future updates and improvements

## AI-Assisted Development

Modern AI tools are also part of my development workflow.

I use AI to assist with tasks such as research, debugging, brainstorming, troubleshooting, and faster iteration while remaining responsible for the architecture, design decisions, implementation, testing, and final product.

## Running Locally

Clone the repository:

```bash
git clone https://github.com/maxsharp13/sharp-sites.git
```

Navigate into the project:

```bash
cd sharp-sites
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```

## Available Scripts

Run the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Start the production build:

```bash
npm start
```

Run ESLint:

```bash
npm run lint
```
